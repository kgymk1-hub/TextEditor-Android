# Pocket Text Editor Android

Kotlin / Jetpack ComposeのAndroidネイティブ版です。日本語UI、Android 8.0（API 26）以上、compileSdk / targetSdk 36。PWAをWebViewで包む構成ではなく、入力はネイティブ、WebViewはプレビュー専用です。

**現在は検証用の開発版です。仕様書の全受入試験を完了した正式版ではありません。** 最新ソースは自動テスト87件とLintの検証を完了しています。署名済みAPKは `release/asset/` にあり、1.0.3-devを署名済みの検証版として [GitHub Releases](https://github.com/kgymk1-hub/TextEditor-Android/releases/tag/v1.0.3-dev) で公開しました。新しい署名鍵への切替と旧版からの移行は [配布説明](docs/RELEASE-1.0.3-dev.md) を参照してください。実機受入は未実施です。元のPWAリポジトリは参照のみです。

インストール用ファイルは `PocketTextEditor-release.apk` です。ダウンロード後、Androidの案内に従って使用したブラウザー／ファイルアプリからのインストールを許可してください。AABは直接インストールするためのファイルではありません。デバッグ版から切り替える場合は、署名が異なるため、アプリ内でバックアップを出力してから旧版を削除し、署名済み版でインポートしてください。

## 実装した機能

- 内部メモの自動保存、SAFで開く／元URIへ上書き／別名保存／コピー保存。書込前の競合検出、書込後の再読込ハッシュ検証、保存中の新しい入力の未保存状態維持。
- 約500msの内部退避（変更可）、タブ・カーソル・選択・スクロール・モード復元、タブ一覧・並替え・複製・閉じた文書の再開。非表示タブを描画せず、大きい本文は退避後にメモリから外します。
- 内部メモ一覧、名前／本文／拡張子／日時検索、お気に入り、ごみ箱と復元、最近の外部ファイル、選択文書の結合コピー・ZIP出力。
- 最大30世代を既定とする履歴、全置換・上書き・削除前の復元ポイント。保持世代・日数・容量とごみ箱期限を設定可能。
- 検索／置換、正規表現、前後移動、件数と全置換確認。全文／ファイル横断検索、保存内容・他文書との簡易行比較。
- Undo/Redo、編集用記号、カーソル・選択移動（長押し繰返し）、行頭／行末、インデント、行複製・削除・移動、指定行ジャンプ、括弧対応・補完、自動インデント、単語候補。
- HTML / CSS / JS / JSON / Markdownの基本ハイライト、行番号・現在行・不可視文字、等幅／標準フォント、サイズ・行間・折返し・ピンチ、テーマとCtrlショートカット設定。
- UTF-8 / UTF-8 BOM / Shift_JISの厳密読書き。変換できない文字は保存を停止。判定失敗時の文字コード再指定と先頭プレビュー。LF / CRLF / CRの保持と明示変換、末尾改行保持、混在改行を無断で統一しない処理。
- HTML連携、コンソール、Markdown（表対応）、CSV（引用符・複数行・検索・列幅・セルコピー・行／列の仮想描画）。JavaScriptは既定OFFで確認時のみ許可、外部通信・端末内ファイルアクセス・ブリッジは禁止。
- ZIPの選択読込、階層・画像等を保持したプロジェクト再パック、元ZIPの競合検査、選択／全タブZIP、パス逸脱・重複名・過大展開の拒否。
- 許可済みSAFフォルダのプロジェクト読込、相対参照の画像・CSS・JSプレビュー。横画面の編集＋プレビュー、分割編集、タブレットのタブサイド表示。
- 現在／選択／全タブのコピー、本文／ファイル／ZIPのAndroid共有。大きいコピーはファイル共有へ誘導。
- 本文・履歴・位置・タブ・設定の明示的なバックアップ出力／追加インポート。外部URIの権限は移行せず、復元した本文は内部メモとして保護します。

本文／履歴はアプリ専用ファイル、メタデータはRoom、設定はDataStore、後処理はWorkManagerです。アカウント、広告、解析SDK、アプリのINTERNET／包括的ストレージ権限はありません。

## ビルド

JDK 17、Android SDK Platform 36、Gradle 8.11.1を使用します。Android Studioでこのディレクトリを開き、SDKを指定してください。

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleRelease :app:bundleRelease
```

Windowsは `gradlew.bat` を使用します。制限付きクラウド環境では、既存のHTTPプロキシとCAを使用する次の補助スクリプトがあります。

```sh
python scripts/build-local.py --java /path/to/jdk17 --sdk /path/to/android-sdk --gradle /path/to/gradle/bin/gradle --project . :app:assembleDebug
```

生成先：

- `app/build/outputs/apk/debug/app-debug.apk`：デバッグ署名済み、実機で試せます。
- `app/build/outputs/apk/release/app-release-unsigned.apk`：署名前のリリースAPK。
- `app/build/outputs/bundle/release/app-release.aab`：署名前のAAB。

秘密のリリース署名鍵は含めていません。`release/asset/` の既存APKは配布用の鍵で署名済みです。再ビルド・今後の更新には同じ鍵を使用します。署名と鍵の保管方法は [RELEASE.md](docs/RELEASE.md) を参照してください。

## 使い方

新規メモは入力後に内部保存されます。外部ファイルは「退避済み」と「元ファイル保存済み」を区別します。「コピーを保存」は元の編集対象を変えません。ZIP由来の文書の保存ボタンは元ZIPを変更せず、メニューの「元ZIPへ保存」で反映します。

HTMLは `href` / `src` の相対参照に対応する文書を使用します。関連プロジェクト以外のタブを一律合成しません。PWA互換の全タブCSS/JS合成は設定で明示的に選べます。JavaScriptの許可はその画面限りです。

アプリ削除で内部メモは失われます。必要な本文と履歴はホームの「その他 → バックアップを書き出す」で保存してください。自動のクラウドバックアップ・独自同期は行いません。

## 大容量対応と検証の範囲

- 1MiB超の本文は128Ki文字以内の区間をネイティブ編集欄に渡します。「前の区間」「次の区間」で移動し、検索・行ジャンプも該当位置の区間を開きます。区間をまたぐUndo/Redoを実装し、20MiBの末尾編集と全文保持を自動テストします。ネイティブの選択・行操作は表示区間が対象です。全文コピー・検索・置換・保存は文書全体が対象です。
- 保存モデルは全文の不変スナップショットです。本文読込・退避はIOスレッドで行い、編集欄は区間ごとに読み込みます。ファイル全体をディスク上のpiece tableで編集する方式ではありません。24MiB上限、空きヒープの事前確認、構文解析・HTML/Markdownプレビューの停止、非表示タブの退避を併用します。
- CSVは引用符の状態を追跡して1回走査し、行の開始／終了位置だけを索引化します。セルは表示行から読み出し、行／列を仮想描画します。500行・50万セルの固定上限はありません。20MiB表と60万セル相当の行数を自動テストします。大容量CSVも表表示できます。
- 本文のRoom FTS4索引は日本語・英語・記号を含む2文字トークンで候補を絞り、原文で厳密照合します。短い検索・正規表現・1MiB超の本文・索引未作成／不一致の本文は走査へ戻し、検索漏れを防ぎます。編集中のタブも照合します。旧DBからは本文と履歴を保持して移行し、索引を再構築します。
- 比較は行番号による簡易表示、補完は単語候補です。言語サーバーや構文木による高度な意味解析は含みません。
- 日本語IME、物理キーボード、TalkBack、回転、OPPO Reno 5A（Android 12）、低性能機、新しいAndroidのSAF・WebView、入力のp95性能は実機受入の対象です。ホスト上の自動テストを端末性能の測定とは扱いません。
- クラウド提供元のオフライン／権限取消／容量不足、強制終了は実機で確認してください。保存先提供元が非アトミックな場合、原本の完全ロールバックは保証できません。
- GitHub配布用の署名済みAPK／AABを生成しました。実機受入は未実施のため検証版として配布します。ストアへの公開は行っていません。

受入手順は [TESTING.md](docs/TESTING.md)、構造は [ARCHITECTURE.md](docs/ARCHITECTURE.md)、基準は [仕様書](docs/SPEC-v1.0.md) を参照してください。

## 成果物の再生成

自動テスト、Debug / Release Lint、APK／AABのビルドが成功した後、レビュー済み変更をコミットし、次を実行します。

```sh
python scripts/package-deliverables.py --output work/deliverables
```

追跡済みソースのZIP、APK／AAB、試験・Lintレポート、ソースコミットと試験件数、SHA-256一覧をまとめます。秘密鍵と作業ディレクトリはソースZIPに含めません。テスト失敗・スキップ・Lintエラー・未コミット変更がある場合は梱包を停止します。
