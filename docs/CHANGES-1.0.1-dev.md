# 1.0.1-dev の変更

- 編集画面の「⋮」を「ファイル・保存」「編集」「検索・履歴・比較」「タブ」「コピー・共有」「ZIP」「表示・設定」「外部ファイルの削除」に整理しました。グループを選ぶと、その操作一覧が開きます。
- 各タブに「✕」ボタンを追加しました。横スクロールするタブ列と大画面のタブ一覧から操作できます。
- タブ列の右側に「✕ 全タブ」を追加しました。
- 個別・全タブとも、確認してから閉じます。キャンセルやダイアログを閉じた場合はタブを維持します。
- 閉じる際に最新の本文を内部退避します。外部ファイルへは保存しません。「タブ → 閉じたタブを復元」から開き直せます。
- 全タブ終了は確認時点のタブを対象とし、その後に開いたタブは保持します。退避に失敗した場合は処理を停止してメッセージを表示します。
