# Pocket Text Editor Android版 仕様書

- **版数**：Ver.1.0（要求仕様確定版）
- **作成日**：2026年10月11日
- **対象**：Androidネイティブアプリ
- **移植元**：`kgymk1-hub/TextEditor`（PWA版 Pocket Text Editor）
- **開発先**：`kgymk1-hub/TextEditor-Android`（現時点では空リポジトリ）
- **目的**：既存PWAの機能を継承し、保存の信頼性、スマホ操作性、編集機能、ファイル管理機能を強化する。以下の機能をすべて開発対象とする。優先順位は実装順を示すもので、省略を意味しない。

## 1. 開発基本方針

1. KotlinとJetpack Composeによる**Androidネイティブアプリ**とする。既存PWAのWebViewラッピングのみで済ませる方式は採用しない。
2. **ローカル完結・オフライン利用可能・アカウント不要**を原則とする。Google Drive等のファイルはAndroidの標準ファイル選択画面経由で扱う。独自のクラウド同期は本仕様に含めない。
3. 主用途は①気軽な文章・メモ作成、②HTML/CSS/JavaScript/JSON/CSV/Markdown等の編集、③ChatGPTなどへの複数ファイルの受け渡し。
4. **文章を失わないことを最優先**し、編集中の自動退避、正式保存、編集履歴を別々に管理する。
5. 狭いスマホ画面をエディタ中心に利用し、高度な操作は必要時に表示する。タブレット・横画面・物理キーボードにも対応する。
6. PWA版は参照実装とする。機能を再実装・改良する一方、PWA版リポジトリには変更を加えない。
7. 初期言語は日本語。配布形式はデバッグAPK、リリースAPK、必要に応じてAABに対応する。

## 2. 想定する使用フロー

- **メモ作成**：新規作成 → すぐ入力 → アプリ内へ自動保存 → 一覧から再開 → 必要なら `.txt` 等として出力。
- **既存ファイル編集**：Androidファイル選択 → 編集 → 保存ボタン → 元ファイルへ上書き → 同じファイルを再度開いて確認可能。
- **別名保存**：編集内容から保存場所とファイル名を指定 → 新規ファイルを作成 → 以後はそのファイルを編集対象にする。
- **コピーを保存**：編集中のファイルの複製を別場所へ書き出す。現在の編集対象と未保存状態は変えない。
- **AIとの連携**：現在タブまたは複数タブの内容をファイル名・相対パス付きで結合コピーし、Android共有機能またはクリップボードで外部アプリへ渡す。
- **複数ファイル作業**：ZIPを開く、ファイルをタブで編集、HTML連携プレビュー、変更を明示的にZIPへ再パックする。

## 3. 保存・上書き・自動退避（最重要）

### 3.1 文書の種類

- **アプリ内メモ**：アプリ専用ストレージで管理。作成後は名称未設定でも自動保存する。タイトル変更、複製、検索、削除、ファイル出力ができる。
- **外部ファイル**：Android Storage Access Framework（SAF）で選択したURIを保持。再起動後も使用可能な読み書き権限が取得できた場合に限り永続化する。提供元の権限・状態によって読取専用や再選択要求となることがある。
- **ZIP由来の文書**：ZIP内の相対パスを保持した作業コピーとして開く。変更は自動で元ZIPへ反映せず、明示的なZIP保存・再パックによって反映する。

### 3.2 操作の意味

| 操作 | アプリ内メモ | 外部ファイル／ZIP作業コピー |
|---|---|---|
| 新規 | アプリ内メモを作成 | ― |
| 開く | メモ一覧から開く | SAFまたはZIP選択から開く |
| 保存 | 保留中の自動保存を即時確定 | 外部ファイル：権限・競合確認後に元ファイルを上書き。ZIP由来：ZIPへの反映はせず、明示的なZIP保存を案内 |
| 名前を付けて保存 | SAFで新規ファイルを作成し編集対象を新ファイルに切替 | SAFで新規ファイルを作成し編集対象を新ファイルに切替 |
| コピーを保存 | 新規ファイルを書き出し、メモのまま編集を継続 | 新規ファイルを書き出し、元の編集対象を維持 |
| 自動退避 | アプリ内部の最新本文を永続化 | 元ファイルには触れず、アプリ内に作業コピーを永続化 |

- `ACTION_OPEN_DOCUMENT`等で既存ファイルを開き、保持した書込可能URIに保存する。**`ACTION_CREATE_DOCUMENT`は同名ファイルの上書きには使わない**。
- 保存後もURIを保持し、次回の［保存］で同一ファイルを再度上書きする。別名保存した場合のみ編集先を新しいURIへ切り替える。
- 保存先へのアクセス失敗、容量不足、読取専用、クラウド提供元のオフライン等では**保存成功と表示しない**。作業コピーは残して再試行・別名保存を案内する。
- 外部ファイルは書込開始前に編集履歴・作業コピーを確保する。提供元によっては上書きが不可逆・非アトミックのため、失敗時の完全なロールバックを保証せず復元手段を提供する。
- 保存処理中に新たな入力が生じた場合、開始時点の内容だけを保存済みとし、その後の入力は未保存のまま維持する（編集リビジョンで管理）。
- 元ファイルの更新時刻・サイズ・可能ならハッシュを記録し、外部で変更された疑いがあれば［再読込］［比較］［コピー保存］［上書き］を提示する。確認なしの上書きは禁止。
- ファイル名・拡張子・保存先・上書き対象が画面から確認できること。同名衝突時は自動的に別のファイルが作られたかを利用者へ明示する。

### 3.3 保存状態の表示

以下の状態を区別する。状態名の表示例はUIに合わせて短縮可能。

1. **保存済み**：アプリ内メモの最新版が確実に保存済み、または外部ファイルへ現在の編集リビジョンまで書き込み済み。
2. **自動退避中**：作業コピーをアプリ内ストレージに書込中。
3. **自動退避済み／元ファイル未保存**：外部ファイルとの差分が残るが復旧可能な作業コピーは保持済み。
4. **元ファイルへ保存中**：外部への上書き書込中。
5. **保存失敗**：元ファイルへの書込失敗。作業コピーは保持。
6. **自動退避失敗**：空き容量等によって作業コピーの永続化にも失敗。目立つ警告と保存誘導を表示。
7. **競合あり／アクセス権なし**：元ファイルへの無条件上書きを停止。

### 3.4 自動退避と復元

- 入力停止後**約500ms**を目安にデバウンスして作業コピーを保存する。タブ変更・アプリのバックグラウンド移行時も速やかに保存する。
- プロセス強制終了やOSによる停止から、本文、開いていたタブ、アクティブタブ、カーソル位置、スクロール位置、選択状態を復元する。キーボードの未確定文字を含む動作を検証する。
- 外部ファイルの正式保存の有無と自動退避の有無を独立して保持する。復元直後に保存先URIと権限を再確認し、書込不能なら作業内容を保持したまま再選択・コピー保存を提案する。
- 自動退避と履歴の保存失敗は握りつぶさずに通知する。本文の削除・タブを閉じる・アプリ内メモ削除には未保存状態に応じた確認を入れる。
- アプリ内メモのデータは原則として一時キャッシュ扱いにせず、正式なアプリ内保存データとして管理する。

### 3.5 編集履歴・安全対策

- 文書単位で定期スナップショットと重要操作直前（全置換、外部上書き、削除等）の復元ポイントを保存する。
- 既定では各文書**最大30世代**とし、保存容量・経過日数による自動整理が可能。上限は設定可能とする。最新作業コピーは履歴整理の対象外。
- 復元前に現在の状態も保護し、過去版へ戻したあとでも復旧できる。
- アプリ内メモは誤削除対策として**ごみ箱**へ移し、既定30日で自動削除。期限・保持条件は設定可能とする。
- 内部保存は一時ファイルへの書込・同期・置換等の安全な手順を採用し、電源断時の破損を抑える。DBメタデータとの不整合も起動時に検出・修復する。

## 4. ファイル管理・タブ

1. **ホーム／ファイル一覧**：アプリ内メモ、最近開いた外部ファイル、お気に入り、ごみ箱を切替。名前、本文、拡張子、更新日時で検索・並べ替え。
2. **文書操作**：名前変更、複製、削除、共有、コピーを保存、複数選択、一括ZIP書き出し。外部ファイル削除・改名などの破壊的操作は権限確認のうえ明示操作のみ。
3. **タブ**：複数同時編集、横スクロール、全タブ一覧、順序入替、タブ複製、閉じたタブの復元、未保存マーク。
4. **タブ数**：現行の5件／10件という固定上限は撤廃。実用上は多数のタブを保持し、メモリ不足対策として非表示タブの描画・解析を停止し必要時に再読み込みする。端末資源の限界は明示する。
5. **作業再開**：前回のタブ構成と編集中の位置を復元。外部ファイルが移動・削除されていても退避済み本文へアクセスできる。
6. **フォルダ／プロジェクト**（拡張機能）：SAFで許可されたフォルダ内の相対パスを一覧表示し、HTML/CSS/JSの関連付け、ファイル横断検索、ZIPへのまとめ出力を行う。権限を得ていないストレージ全体の走査は行わない。

## 5. 画面・UI/UX

### 5.1 画面構成

- **ホーム画面**：［新規］［開く］、最近の文書、アプリ内メモ一覧、お気に入り、検索。
- **編集画面**：上部にファイル名・保存状態・［戻す］［やり直す］［保存］［その他］。その下にコンパクトなタブバー、中央に広い編集領域。
- **表示切替**：［編集］［HTML］［CSV］［Markdown］を拡張子に応じて表示。プレビュー更新ボタンを配置。
- **補助操作**：検索・置換・文字コード・ZIP・共有・設定は必要時にシートやメニューを開く。多段の常設ツールバーは廃止。
- **フルスクリーン**：上部操作やステータスバーを最小化し本文を最大表示。編集画面へワンタップで戻る。
- **横画面／タブレット**：編集＋プレビューの左右分割と可変境界、タブ一覧のサイド表示を用意する。

### 5.2 入力操作

- **コーディング用記号バー**：既存の `Tab { } [ ] ( ) < > " ' \` / \ = ; : . , _ -` 等を継承。表示は［常時］［編集中のみ］［非表示］。配置と内容を編集可能。
- 記号バーに［カーソル←→］［行頭］［行末］［選択範囲調整］［Undo］［Redo］［インデント増減］を追加。長押し・繰り返し移動にも対応。
- 日本語IME、英数字IME、コピー／貼付け、ハードウェアキーボード、改行入力、ドラッグ選択との整合性を確認。
- スマホではソフトキーボード出現時に余分なパネルを隠し、編集中の行がキーボードで隠れないこと。
- 拡大縮小（ピンチまたは設定）、文字サイズ、行間、折り返しON/OFF、等幅フォント、行番号ON/OFF。
- ライト／ダーク／システム連動。文字サイズ拡大、TalkBack、コントラスト、押しやすいタップ領域にも対応。
- 物理キーボード向けに `Ctrl+S`、`Ctrl+Z`、`Ctrl+Y`、`Ctrl+F`、`Ctrl+H`、`Ctrl+N`、`Ctrl+O`、`Ctrl+Tab` などを提供（環境に応じたキー割当を許可）。

## 6. テキスト編集機能

- **基本**：新規・開く・上書き・別名保存・コピー保存、切り取り、コピー、貼付け、Undo/Redo、多段階編集履歴。
- **検索／置換**：次・前の一致、件数表示、1件置換、全置換、大文字小文字区別、正規表現、検索位置維持。全置換前に置換件数確認と履歴保存。
- **表示**：文字数、行数、行／列番号、選択文字数、エンコーディング、改行コード、保存状態、カーソル位置・スクロール位置記憶、指定行ジャンプ、現在行ハイライト。
- **コード編集**：HTML、CSS、JavaScript、JSON、Markdownの構文ハイライト、括弧対応表示、括弧自動補完（ON/OFF）、自動インデント、Tab/スペース切替、行複製・削除・移動、まとめてインデント調整、空白／Tab／改行表示（ON/OFF）、補完候補。
- **拡張**：保存済み内容と編集中の差分比較、ファイル間比較、全文・ファイル横断検索。単なるテキストの編集にも邪魔にならないよう高度な機能は任意表示。
- **文字コード**：UTF-8、UTF-8 BOM、Shift_JISを読み書き対応。読込時にBOMを検出し、判定困難な場合はエンコーディング再指定と再読込プレビューを提供。UTF-8で表現不能な文字の変換やShift_JIS保存時の文字欠落は警告。
- **改行コード**：LF／CRLF／CRを認識し、既存ファイルでは原則保持。明示的な変換も可能。末尾改行の有無を勝手に変えない。
- **その他**：`.txt .csv .html .htm .js .css .json .md` を基本対象とし、その他のテキスト系拡張子も開ける。バイナリと判断したファイルは無理に編集せず警告する。

## 7. プレビュー機能

### 7.1 HTML

- 現在のHTML文書をWebViewで表示。編集内容の手動更新に対応し、設定で自動更新も選べる。
- **連携プレビュー**：対象HTMLに関連付けたCSS/JavaScriptを反映する。単に全タブのJS/CSSを無条件合成しない。PWA版の簡易全タブ連携は互換オプションとして選択可。
- 実行前にJavaScript有効化の要否を確認し、既定はOFF。不審なHTML/JSや外部URLを勝手に実行・読み込みしない。プレビューはアプリ本体から権限を分離し、不要なWebView権限・ブリッジを無効化する。
- プレビュー用コンソール（`console.log`、エラー・警告、行番号の取得可能な範囲）を搭載。再読み込み、プレビューの全画面表示、編集画面との分割表示に対応。
- SAFの許可範囲にある相対パスや関連文書を安全に解決し、ローカル画像・スタイル等もプレビューできる構成を検討する。任意の端末内ファイルへのアクセスは認めない。

### 7.2 CSV

- 引用符・カンマ・改行を適切に処理し、表形式で閲覧する。ヘッダー行ON/OFF、列幅調整、セル選択とコピー、表内検索。
- 行・列の仮想化により大きいCSVでも表示負荷を抑え、500行の固定表示上限を撤廃する。全件表示に支障がある場合は一部読込である旨を明示。
- 初期段階は表形式での**閲覧**を基本とし、値の編集はテキスト側で行う（表セル編集は将来拡張）。

### 7.3 Markdown

- 見出し、箇条書き、表、コードブロック、リンク等のMarkdownプレビューを追加。ローカル閲覧を基本とする。

## 8. ZIP入出力・共有

1. ZIPファイルを選択して中身を一覧表示。対応するテキストファイルを個別または複数まとめてタブへ開く。
2. ZIP内の**フォルダ階層・相対パス**を保持。編集後は明示的な［ZIPとして保存］［ZIPのコピーを保存］で再圧縮。元ZIPの上書きは権限・競合の確認後のみ。
3. 開いている全タブ、選択タブ、指定フォルダをZIP化。名前の重複時は勝手な上書きを避け、衝突を通知して一意名への変更を提案。
4. ZIP展開時は `../` 等によるパス逸脱、絶対パス、異常な圧縮率・巨大展開、エントリー過多を検知して安全に拒否する。
5. **現在タブコピー**、**全タブ結合コピー**、**選択タブ結合コピー**を搭載。結合時は `===== 相対パス/ファイル名 =====` の区切りとタブ順を保持。
6. Android共有機能で本文テキスト、書き出したファイル、ZIPを他アプリへ渡せる。共有は利用者操作時のみ行い、自動で外部送信しない。
7. 大容量テキストをクリップボードへ送る場合はサイズを表示し、必要ならテキストファイル共有を推奨する。

## 9. データモデル・保存先

- **Document**：文書ID、区分（内部／外部／ZIP）、表示名、相対パス、拡張子、URI、本文内部保存先、文字コード、BOM有無、改行コード、更新時刻、保存時ハッシュ／リビジョン、お気に入り、削除状態。
- **EditSession / Tab**：タブID、文書ID、編集中のリビジョン、編集中本文の退避パス、カーソル、選択範囲、スクロール、表示モード、最終操作時刻。
- **Revision**：履歴ID、文書ID、時刻、本文スナップショット、変更理由、サイズ、復元元。
- **RecentFile**：URI、表示名、最終閲覧時刻、アクセス可否、読み書き権限状態。
- **Preferences**：テーマ、文字サイズ、行間、補助バー、折り返し、エンコーディング既定値、履歴数、タブ設定等。
- 本文・履歴はアプリ専用ストレージ内のファイルで管理し、**Room**にメタデータと検索索引、**DataStore**に設定を保持。大容量本文全体を毎キー入力時にDBへ再保存しない。
- 作業コピーの作成、正式保存の完了、履歴作成のタイミングをリビジョン番号で追跡する。変更がないデータは重複保存を減らす。
- バックアップエクスポート／インポートを提供する。アプリ削除時にはアプリ内メモが失われ得るため、明示的なエクスポートとバックアップの説明を設ける。
- 外部クラウドファイルの反映完了時刻は提供元に依存するため、ローカル書込成功をクラウド同期完了と誤表示しない。

## 10. 技術構成

| 要素 | 採用方針 |
|---|---|
| 言語／UI | Kotlin／Jetpack Compose、MVVMなどの分離構成 |
| コード編集 | `sora-editor` 等の成熟した編集コンポーネントを比較・採用。ComposeとはAndroidViewで連携可能。日本語IMEと大容量性能を検証 |
| アプリ内データ | アプリ専用ファイルストレージ＋Room |
| 設定 | DataStore |
| 外部ファイル | Storage Access Framework（SAF）、ContentResolver、永続URI権限 |
| 文字コード | JVM/Android標準の適切なエンコーダー／デコーダー、エラー検出付き |
| HTMLプレビュー | セキュリティ制御したWebView |
| CSV | RFC 4180相当の引用規則を扱えるパーサー＋仮想スクロールUI |
| ZIP | Android対応ライブラリ／標準API。安全制限を実装 |
| 定期的な後処理 | WorkManager（履歴整理等）。入力時自動退避は即時処理で実装 |
| バージョン管理 | GitHub `kgymk1-hub/TextEditor-Android` |

- **最低対応OSの目標**：Android 8.0（API 26）以上。実装時に選定する編集ライブラリ等との互換性を検証して確定する。
- **動作確認の主対象**：Android 12実機（OPPO Reno 5A）、加えて低性能端末と新しいAndroidバージョン、画面回転・タブレット形状。
- **targetSdk**：実装・公開時のAndroid／Google Play要件に合わせて決定する。API値を仕様書で古く固定しない。
- 編集ライブラリを利用する場合は、ライセンス条項・配布時表記・改変時義務を満たす。`sora-editor` は現行のGitHub LICENSEでLGPL-2.1-or-laterを掲げているため、その条件を確認する。
- 完成するアプリはライブラリに依存した処理とアプリ独自のファイル管理・UIを分離し、将来交換しやすい設計とする。

## 11. 非機能要件・セキュリティ

- **オフライン優先**：ネット接続がなくてもアプリ内メモの作成、編集、検索、プレビュー（外部依存のない範囲）、ZIP操作が使える。
- **性能目標**：一般的な1MBのUTF-8文書を数秒以内に開き、通常の入力・スクロールが明らかな遅延なく動作すること。目安としてキー入力処理の応答p95を100ms以内とする。実機計測で調整する。
- **大容量**：5MB級の文書は通常利用を検証し、20MB級は段階読込・構文解析制限・警告等の大容量モードで扱えることを目標とする。処理可能サイズを断定せず、無応答・メモリ枯渇を防ぐ。
- **安定性**：書込失敗、空き容量不足、権限取消、プロセス終了、再起動、画面回転中に本文を不必要に失わない。重い処理はUIスレッドから分離する。
- **プライバシー**：アカウント・広告・解析SDK・独自サーバーは初期版では不要。共有以外の外部送信を行わない。ログに本文・秘密情報を出力しない。
- **権限最小化**：端末ストレージ全体への包括的アクセスを原則要求せず、SAFの利用者選択に限定。
- **プレビュー安全性**：WebViewのJavaScriptは既定OFF、不要なファイルアクセス・権限・JavaScriptブリッジは禁止。外部通信は既定で遮断し、許可するなら対象とリスクを明示。
- **保存の整合性**：元ファイルの競合検出、文字コード変換警告、書込の成功検証、失敗時の救済経路を必須とする。
- **アクセシビリティ**：日本語表示・TalkBack・文字拡大・視認性・タップしやすさを確認。

## 13. 移植・互換性

- PWA版の主要機能である、複数タブ、ファイル入出力、検索・置換、記号バー、HTML/CSV/連携プレビュー、ZIP開閉、文字コード設定、ダークモード、現在タブコピー、全タブ結合コピー、自動バックアップを**機能継承**する。
- 保存動作はPWA版とは意図的に変更する。PWAの「DL保存」はAndroid版では「コピーを保存」相当とし、［保存］は確実に現在の保存先を対象にする。
- PWAの`localStorage`はAndroidネイティブ版から自動で引き継がない。PWA版から書き出したテキストやZIPを手動でインポートできることを移行手段とする。
- プレビュー、ZIP、文字コード変換の正常系・境界条件は既存PWAの振る舞いを参考にしつつ改善する。
- GitHubリポジトリにはREADME、アーキテクチャ概要、依存ライブラリのライセンス表記、ビルド方法、テスト方法、サンプルファイルを含める。

## 15. 受入テスト／完成判定

1. 新しいアプリ内メモが入力後自動保存され、強制終了・再起動後に復元できる。
2. SAFで開いた書込可能な既存ファイルを編集し、［保存］で元の同一ファイルが更新される。複製ファイルを増やさない。
3. ［名前を付けて保存］で新ファイルを作成し、その後の［保存］が新ファイルを更新する。
4. ［コピーを保存］で別ファイルを書き出しても、元文書の編集先や未保存状態が変わらない。
5. 自動退避済みでも正式な外部保存前には「元ファイル未保存」と分かる。正式保存失敗時に「保存済み」と表示しない。
6. 保存中の追加編集が誤って保存済み扱いにならない。保存中の中断でも退避本文が残る。
7. 他アプリで元ファイルを書き換えた場合は競合を表示し、無確認で上書きしない。
8. URI権限取消、読取専用、クラウドオフライン、空き容量不足でも復旧可能な本文を保持する。
9. Shift_JIS、UTF-8、UTF-8 BOM、LF、CRLFの読み書きを試験し、不要な改行・BOM変更や文字欠落がない。
10. 日本語IMEで連文節変換、改行、削除、範囲選択、Undo/Redo、記号バー挿入を正しく操作できる。
11. タブを10件以上開いて切替・復元し、隠れたタブのデータが失われない。
12. HTML/CSS/JS連携プレビュー、JS無効化、コンソール、CSV引用符付き複数行、Markdown表示が動作する。
13. ZIPのフォルダ構造が保持され、明示的に保存するまで元ZIPは変化しない。悪意のあるパス／異常なZIPを拒否する。
14. 現在タブ・選択タブ・全タブコピーの区切り・順序・ファイル名が正しい。共有先で利用できる。
15. アプリ内メモ一覧の検索・お気に入り・複製・削除・ごみ箱・復元が動作する。
16. 通常の1MB、5MB級、20MB級のファイルで性能・エラー表示を試験し、UI無応答やデータ破壊を起こさない。
17. スマホ縦画面、横画面、タブレット、ダークモード、文字サイズ拡大、TalkBackで主要操作ができる。
18. アプリがネットワーク不通でも中核機能を使用でき、明示的な共有以外のテキスト外部送信を行わない。
19. Debug/Release APKビルドが成功し、依存ライブラリのライセンス表記・README・ビルド手順が揃う。
20. Phase A～Cの採用要件をすべて実装・試験し、未実装項目を残す場合はREADMEに正確に明示する。
