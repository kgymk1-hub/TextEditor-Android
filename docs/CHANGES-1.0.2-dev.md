## 使い方の例

- 無題文書にHTMLを貼り付けて「HTML」を選びます。複数タブを簡易合成する場合は、設定の「PWA互換・全タブCSS/JS合成」をONにします。JSの実行は別途確認して許可します。
- Shift_JISを読み、UTF-8 BOM付きのコピーを作る場合は、設定の「読込の既定文字コード」をShift_JIS、「書出しの既定文字コード」をUTF-8 BOMにして「コピーを保存」を使います。元ファイルの上書き文字コードは変わりません。
- ZIP内の別のファイルを後から追加する場合は「ZIP内ファイル一覧」を使います。
