# テストと受入

## 自動テスト

`./gradlew :app:testDebugUnitTest :app:lintDebug :app:lintRelease` を実行します。JUnitとRobolectric（API 28のAndroid APIシミュレーション）を使用します。

- `TextToolsTest`：UTF-8／BOM／Shift_JIS、改行・末尾保持、変換エラー、バイナリ拒否、CSV複数行／引用符／1500行、ZIPパス／重複／圧縮率／エントリー上限、結合順、通常／正規表現検索。
- `StorageTest`：Roomと本文の再生成・再読込、カーソルと11番目タブ位置、古い退避の拒否、外部文書と正式保存状態の分離、30世代保持、欠損からの履歴復旧、同じURIへの上書きと再読込、破損応答・読取専用時の失敗と本文保持、FTS更新と日本語部分一致、v1→v2移行、ディレクトリ逸脱拒否、保存上限の事前確認、設定の範囲検証。
- `SaveRulesTest`：保存中の追加リビジョンを未保存として保持、将来リビジョンの拒否、LF／CRLF／CRのネイティブ表示用変換と完全往復、混在改行の保持。
- `NativeEditorTest`：日本語選択と挿入、Undo/Redo、行頭／末尾、範囲インデント、大容量区間の往復・区間外本文保持・区間をまたぐUndo/Redo・モード閾値をまたぐUndo、20MiB末尾編集、絵文字を分断しない移動、InputConnectionの未確定→確定。

- `LargeDataTest`：20MiB CSV、20万行／60万セル相当の表、行索引検索、引用符エラー、サロゲート／CRLF境界、Unicodeの大小文字候補。
- `ViewModelTest`：退避タブの再読込、退避された本文の削除前履歴、バックアップの追加復元とモード・履歴保持、保存前の入力を使う横断検索、削除中の追加入力による取消と本文保護、全タブ終了時の最新本文退避と復元、外部ファイルの未保存維持、確認後に開いたタブの保持。メインループを動かしながら非同期保存の完了を待ちます。

最新のテスト件数・Lint結果・ソースコミットは配布物の「検証結果.md」と「build-manifest.json」に記録します。ビルドで生成されたJUnit XML・HTML、Debug / Release Lintレポートも同梱します。所有者署名設定は一時的な試験鍵で署名APK・AABを生成し、署名検証まで確認します。試験鍵と試験署名版は配布物に含めません。

## 実機で実施する20項目

仕様書15節に対応する試験です。現時点では自動テストで一部を確認していますが、下表の実機完了は未確認です。試験にはサンプル・テスト用の文書を使用してください。

| 項目 | 操作と期待結果 |
| --- | --- |
| 1 内部メモ | 入力後1秒待ち、強制停止→再起動。本文・タブ・選択・スクロールを復元 |
| 2 上書き | SAFの既存文書に追記→保存。同じ文書が更新され、複製を増やさない |
| 3 別名 | 別名保存後に再編集→保存。新URIだけが更新される |
| 4 コピー | コピー保存後も編集先・未保存マークが変わらない |
| 5 状態 | 退避済みでも外部未保存。提供元エラー時は成功と表示しない |
| 6 並行入力 | 遅い提供元への保存中に追記。追記は未保存のまま、退避に残る |
| 7 競合 | 他アプリで原本を書換え。比較／再読込／コピー／確認付き上書きを選択できる |
| 8 障害 | URI権限取消、読取専用、オフライン、空き容量不足で本文を救出できる |
| 9 変換 | UTF-8／BOM／SJIS、LF／CRLF／CR、混在と末尾をバイト比較。絵文字SJISは拒否 |
| 10 IME | 日本語の連文節・未確定文字・Enter・削除・選択・Undo・記号で本文を失わない |
| 11 タブ | 15件以上の切替・並替え・閉じる・再起動で全本文を保持 |
| 12 プレビュー | サンプルHTML関連CSS/JS、JS OFF／許可、コンソール、CSV、Markdownを確認 |
| 13 ZIP | 画像と階層を保持し再パック。明示保存まで原本不変。危険パス・巨大展開を拒否 |
| 14 共有 | 選択／全タブの順序とパス、コピー、Android受信先で本文／ファイル／ZIPを確認 |
| 15 一覧 | 本文検索、お気に入り、複製、ごみ箱、復元、期限設定を確認 |
| 16 性能 | scripts/make-fixtures.pyの1／5／20MiBで時間・入力p95・ヒープを記録。上限・拒否も確認 |
| 17 UI | 縦／横／タブレット／分割／ダーク／OS文字倍率／TalkBackで主要操作可能 |
| 18 オフライン | 機内モードで内部編集、プレビュー、ZIPを利用。外部URL・JS通信が遮断される |
| 19 配布 | Debug／Release／AABの生成、本番署名、ライセンス表示、実機インストール |
| 20 全体 | READMEの残項目が解消し、Phase A〜Cの要件ごとの実機記録が揃う |

性能値はRobolectricの実行時間から推定しません。物理端末で測定し、機種・OS・IME・ファイルサイズ・測定条件と一緒に記録してください。

バックアップ復元は既存データへ追加します。URI権限は移行せず、外部文書は内部メモになり、本文・履歴・位置が保持されることを確認します。

## PWA互換機能の検証

- `PwaCompatibilityTest`：CSS／JSの大小文字、head／bodyへの合成位置、script終了文字列とドル記号、JS無効、ZIPの重複名とパス逸脱、CSV列数と列ラベル、前後参照を含む正規表現の1件置換。
- `CsvPreviewTest`：ヘッダー・行番号・空セル、見出しと本文の共通横スクロール、固定ヘッダー、Zを超える列ラベルをCompose UIとRobolectricで確認。
- `PwaUiTest`：txt文書のHTML表示から検索・置換・Undoまでの画面操作、未保存件数表示、IME非表示での記号バー表示。
- `ViewModelTest`の追加項目：文書IDとリビジョンによる置換先保護、独立した文字コード設定、コピーによる原本設定の保持、外部上書きの文字コード保持、ZIP一覧の継続利用、重複名ZIPの本文保持、退避CSSの再読込。
- `NativeEditorTest`の追加項目：別文書／古いリビジョンの置換を拒否し、正しい対象では置換とUndoができること。

画面テストも実機試験ではありません。HTML合成テストは生成文字列を検証しており、実端末のWebViewでのJS実行結果までは保証しません。
