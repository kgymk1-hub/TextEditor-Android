# 1.0.3-dev：PWAのアイコンとUIの継承

2026年10月13日。PWAのREADME、index.html、css/style.css、js/app.js、icons/icon.svg、manifest.jsonと、Android仕様書の画面・UI/UXを照合しました。

## アイコン

PWA版の青い背景、白い文書、青い罫線、黄色い鉛筆をAndroid VectorDrawableへ移植しました。色と図形はPWAのSVGを基にしています。

- ランチャーはAdaptive Iconに対応し、背景と前景を分離しました。
- 前景を安全領域に収め、端末の丸形・角丸形のマスクで文書や鉛筆が切れにくい配置にしました。
- 通常のベクターアイコンも保持し、ホーム画面のブランド表示に使用します。
- AndroidManifestの通常・丸形アイコンを更新しました。OSのテーマ付きアイコン用の単色シルエットにも対応します。

参照：[PWAの元SVG](https://github.com/kgymk1-hub/TextEditor/blob/19ea48576a7250808ee4a6bbc9c7e06ba3c99b55/icons/icon.svg)。PWAリポジトリ自体は変更していません。

## UIで継承した工夫

| PWAでの工夫 | Androidへの反映 |
|---|---|
| 青を基調とした明快な配色、白／灰色の背景、濃色のダーク画面 | 青を主色とするライト／ダーク配色へ変更。本文・行番号も読みやすい中立色へ揃えました。構文色や現在行の強調は維持します。 |
| 「暗／明」で素早くテーマを切替 | ホームと編集画面に切替ボタンを追加。設定のシステム連動も維持します。ステータス／ナビゲーションバーの色とアイコン表示もテーマに合わせます。 |
| タブ列右側から新しいタブを追加 | 常に押せる「＋」を追加。個別の「✕」と「✕ 全タブ」、閉じる前の確認は維持します。 |
| タブの横スクロールと長い名称の省略 | 横スクロールを維持し、長い名称が操作を押し出さない幅と1行省略を設定しました。全名称・URI・文字コードはファイル名をタップして確認できます。 |
| 狭い画面でも操作を押しやすくする | 狭い画面や文字拡大時はファイル情報と操作を分け、操作列を横スクロールにします。広い画面では1行にまとめます。原則48dp以上のタップ領域を維持します。 |
| コピーなどの補助操作を必要時だけ表示 | 「ツール」から検索、現在タブコピー、全タブ結合コピー、ZIP、設定へ短い導線を追加しました。従来のグループ化メニューも維持します。 |
| 編集領域を広く使う | ソフトキーボード表示中は補助メタデータを隠し、編集中の表示切替列も抑えます。表示切替は「その他 → 表示・設定」からも操作できます。記号バーの設定は維持します。 |

保存状態と未保存件数は別々に配置し、長い状態名で件数が隠れにくくしました。元ファイル情報は「文書情報」で省略せず確認できます。

## 維持したAndroid版の改良

グループ化メニュー、個別／全タブの確認付き終了、内部退避と履歴、SAFの保存先保持と競合確認、全タブコピー、任意文書のHTML／CSV／Markdown表示、PWA互換CSS／JS合成、CSVの固定見出し・共通スクロール・仮想描画、独立した文字コード設定、ZIP一覧の継続利用と重複名解消、フルスクリーン、分割表示／分割編集、タブレットのサイド一覧、物理キーボード対応を維持しています。

versionCodeは4、versionNameは1.0.3-devです。既存の署名済み配布APKは1.0.0-devのまま保持しており、この実装だけでは配布APKは更新されません。
