# 署名済み検証版の公開再開

このブランチは新環境へ公開用ファイルを移すためのものです。秘密鍵や資格情報は含みません。既に署名済みなので、公開のための再ビルドや署名鍵の移行は不要です。

既存Release ID409933157、タグv1.0.0-devを使用します。初回確認時点でDraft/Prerelease、添付0件でした。mainのソースコミットはa4c72bc08d64b3f90a27b5db27c7edfa95688451です。

新環境でこのブランチのdistribution/v1.0.0-devを取得し、次を実行してください。

```sh
python distribution/v1.0.0-dev/publish.py
```

GitHub認証とuploads.github.comへの通信許可が必要です。スクリプトはローカルのSHA-256、アップロード済みファイルのSHA-256、添付一覧を照合してからDraftを解除し、Prereleaseを維持します。既存添付が一致していれば再アップロードしません。失敗時に秘密情報を追加したり署名鍵を再作成しないでください。

公開後、ReleaseページとAPKのダウンロードを確認してください。秘密鍵は旧環境のwork/private-signingに保持しており、所有者による別の安全な非公開場所へのバックアップは別作業です。
